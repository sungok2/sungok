# Wireless Explorer — Google Play 등록 초안 (한국어)

> **등록 전 필수 확인:** 실제 Galaxy 성능 시험, 개인정보처리방침 URL, 고객지원 연락처, 서명키, Play Console 유료 앱 판매 설정과 해당 계정의 테스트 요건을 충족해야 합니다. 검증되지 않은 성능·숫자·지원 모델을 상품 설명에 넣지 마세요.

## 앱 이름
Wireless Explorer — 무선기기 탐색

## 간단한 소개 (80자 이내 목표)
BLE·Wi-Fi·Bluetooth 탐지 기록을 보기 쉽게 검색·분석·저장하는 도구

## 상세 설명
주변에서 Android가 실제로 수신할 수 있는 무선기기 정보를 체계적으로 정리해 보세요.

Wireless Explorer는 BLE 광고, 검색 가능한 일반 블루투스 기기, 주변 Wi-Fi 접속점, Wi-Fi Direct 피어와 로컬 네트워크 서비스 정보를 한 화면에 모읍니다. 탐색 결과는 휴대전화에 저장되며 이름·주소·프로토콜로 찾고, 신호 강도 추이를 비교하고, CSV·JSON과 진단 보고서로 내보낼 수 있습니다.

**기능**
- BLE / Bluetooth / Wi-Fi / Wi-Fi Direct 탐색과 프로토콜별 상태 확인
- 수신 RSSI 및 최근 신호 변화 확인(거리·위치 추정 아님)
- 이름·주소·서비스 정보 검색 및 정렬
- 이전 기록과 이번 탐색에서 새로 확인된 주소 구분
- JSON 백업·복원, CSV 내보내기, 텍스트 진단 보고서
- 사용자의 별도 확인 후 허가된 사설 Wi-Fi LAN의 제한된 TCP·UPnP 서비스 응답 확인
- 서버 계정 불필요, 기본 탐색 기록 로컬 저장

**중요한 한계**
Android가 접근할 수 없는 무선 방식, 광고하지 않는 기기, 검색 가능 모드가 꺼진 기기, 응답하지 않는 네트워크 장치는 표시되지 않을 수 있습니다. 탐지한 MAC/IP 주소 또는 서비스 항목 수가 실제 물리기기 수와 같지는 않습니다. 일부 Android 기기나 OS 버전에서는 탐색 권한·운영체제 제한 때문에 표시되는 정보가 다를 수 있습니다. 실제 주변 기기의 위치 또는 소유자를 식별하지 않습니다.

**개인정보**
기기 주소, 이름, 신호 강도, 발견 시각이 휴대전화 내부에 저장됩니다. 별도 서버로 자동 업로드하지 않습니다. CSV·JSON 파일을 내보낸 뒤에는 사용자가 파일을 관리해야 합니다. 자세한 내용은 공개 개인정보처리방침을 참조하세요.
