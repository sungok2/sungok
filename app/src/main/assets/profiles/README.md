# Printer model profiles

Profiles contain constrained model, PDL, resolution, and job-size data only. The app validates every field against an allowlist and never downloads executable code. Remote refresh source: `printer-profiles/` in the `sungok2/sungok` GitHub repository.

`WF-C5390.profile` is a protocol-reviewed starting profile based on Epson's published PCL/PS3 support. It is not hardware-tested on a Galaxy phone or this printer.
