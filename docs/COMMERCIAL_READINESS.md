# Galaxy Universal I/O 0.13.0 출시 검증 기준

이 빌드는 유선 USB 인쇄의 현장 검증 후보입니다. 지원 상품 설명에는 실물 시험을 통과한 프린터와 Galaxy 조합만 기재합니다.

| 검증 항목 | 합격 조건 |
|---|---|
| 첫 연결 | 전원이 켜진 WF-C5390의 뒷면 PC 연결용 포트와 데이터 케이블을 연결하면 Android가 장치를 열거한다. |
| 권한 | 승인 후 같은 프린터의 진단이 이어진다. 거부 후 재시도가 가능하다. |
| 인쇄 | A4 한 장과 컬러 다중 페이지 PDF가 실제 출력된다. 페이지 순서·크기·색을 확인한다. |
| 복구 | 데이터 케이블 분리, 용지 없음, 프린터 재시작 후 앱이 멈추지 않으며 완료로 오표시하지 않는다. |
| 오프라인 | Wi-Fi와 모바일 데이터를 끈 상태로 내장 프로파일로 출력한다. |
| 업데이트 | 이전 서명본에서 삭제 없이 업데이트하고 USB 진단과 인쇄를 반복한다. |

실물 시험표에는 Galaxy 모델, Android/One UI 버전, 프린터 펌웨어, 케이블·OTG 구성, 앱 버전 및 출력 결과를 기록합니다. HP·Canon·Samsung은 모델별 직접 USB 실증을 마칠 때까지 제조사 연결 안내 범위로 표시합니다. WF-C5390 시험 결과를 스캐너 호환성으로 확대 적용하지 않습니다.

## 상용 배포 차단 조건 (2026-11-22)

- [ ] Galaxy 실제 기기에서 USB Host 열거 및 앱 선택/권한 승인 반복 검증
- [ ] 프린터에서 단일 페이지·다중 페이지 실제 출력, 색상·크기·여백·용지없음 복구 검증
- [ ] 스캐너 실제 장치에서 평판·ADF 검증(지원한다고 명시할 모델만)
- [ ] Android 13 및 Android 16 실기 확인; 에뮬레이터 테스트는 대체 불가
- [ ] 동일 릴리스 키로 생성한 APK 및 AAB 서명 확인, 설치본 무삭제 업데이트 확인
- [ ] 사용자 개인정보 처리방침과 Play Console 앱 데이터 보안 신고 검토
- [ ] 지원 기기 목록은 실증 결과만 표기하고, 제조사 전용 USB 모델은 미지원으로 명시

자동 빌드가 성공하더라도 상기 물리 장비/배포 조건을 충족하기 전에는 '판매 준비 완료'나 '범용 USB 지원'이라고 표시하지 않습니다.

## 0.13.0 UI 추가 합격 조건

- [ ] 320×640 Android 13 에뮬레이터에서 하단 메뉴 고정, 긴 진단 본문 스크롤, 인쇄·스캔 메뉴 전환 확인
- [ ] 접근 권한 없이 화면에서 1단계 연결, 권한 필요시 2단계, 권한 승인시 3단계 확인
- [ ] 효과음 선택을 끄고 켠 상태, 시스템 무음 및 진동 제한 시 사용자 선택 존중
- [ ] 앱 강제 종료 후 설정 복원, 대체 텍스트, 큰 글씨 설정, Android 16 시스템 바와 겹침 없는지 현장 확인
- [ ] UI 최적화 후 실제 프린터 통신 처리량, 인쇄·스캔 결과에 회귀 없음
