# Galaxy Universal I/O 0.12.4 출시 검증 기준

이 빌드는 유선 USB 인쇄의 현장 검증 후보입니다. 지원 상품 설명에는 실물 시험을 통과한 프린터와 Galaxy 조합만 기재합니다.

| 검증 항목 | 합격 조건 |
|---|---|
| 첫 연결 | 전원이 켜진 WF-C5390의 뒷면 PC 연결용 포트와 데이터 케이블을 연결하면 Android가 장치를 열거한다. |
| 권한 | 승인 후 같은 프린터의 진단이 이어진다. 거부 후 재시도가 가능하다. |
| 인쇄 | A4 한 장과 컬러 다중 페이지 PDF가 실제 출력된다. 페이지 순서·크기·색을 확인한다. |
| 복구 | 데이터 케이블 분리, 용지 없음, 프린터 재시작 후 앱이 멈추지 않으며 완료로 오표시하지 않는다. |
| 오프라인 | Wi-Fi와 모바일 데이터를 끈 상태로 내장 프로파일로 출력한다. |
| 업데이트 | 이전 서명본에서 삭제 없이 업데이트하고 USB 진단과 인쇄를 반복한다. |

실물 시험표에는 Galaxy 모델, Android/One UI 버전, 프린터 펌웨어, 케이블·OTG 구성, 앱 버전 및 출력 결과를 기록합니다. HP·Canon·Samsung은 모델별 직접 USB 실증을 마칠 때까지 제조사 연결 안내 범위로 표시합니다. WF-C5390 시험 결과를 스캐너 호환성으로 확대 적용하지 않습니다.
