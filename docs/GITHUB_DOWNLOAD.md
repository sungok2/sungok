# Galaxy Universal I/O v0.13.0 — Android QA 다운로드

> **시험용 APK(디버그 서명). 정식 판매·배포판이 아닙니다.**
> Android 8.0 이상. GitHub Actions에서 Android 13 에뮬레이터 스모크 테스트를 통과한 커밋에서만 이 사전 공개 다운로드를 생성합니다.

## 갤럭시에서 받기

1. GitHub의 **Releases** 페이지에서 `Galaxy Universal I/O 0.13.0 — QA` 시험 릴리스를 선택합니다.
2. **Assets** 아래 `GalaxyUniversalIO-v0.13.0-QA-debug.apk`를 누릅니다. **Source code (zip)**은 APK가 아닙니다.
3. 브라우저가 APK 다운로드 경고를 표시하면 출처가 `github.com/sungok2/sungok`인지 확인합니다. 출처가 다른 파일은 설치하지 않습니다.
4. 삼성 **내 파일 → 다운로드**에서 APK를 선택하여 설치합니다. Android가 요청하는 경우 해당 앱에 한해 ‘이 출처의 앱 설치 허용’을 승인하고, 설치 후 다시 해제할 수 있습니다.
5. 설치가 실패하면 파일 크기/해시와 저장 공간, 기존 앱 서명을 확인합니다. 서명이 다른 기존 APK와 같은 앱 ID를 가진 경우에는 덮어쓰기가 불가능합니다.
6. 릴리스 자산의 `SHA256SUMS.txt`와 받은 APK의 SHA-256이 일치하는지 확인할 수 있습니다.

## 꼭 알아둘 점

- 빌드 ID: `com.galaxyuniversalio.debug`. 정식 릴리스의 앱 ID(`com.galaxyuniversalio`)와 다르며 정식판 업데이트 경로가 아닙니다.
- QR 또는 다른 웹사이트에서 우회 설치시키는 다운로드 앱을 요구하지 않습니다.
- USB 장치 연결·프린터/스캐너 동작은 모델별 실제 테스트가 필요합니다. USB 인식과 실제 인쇄는 다릅니다.
- 직접 USB 인쇄와 제조사 네트워크 인쇄는 별도 경로입니다.
- 자동화 스모크 성공만으로 상용화/실물 호환성이 보증되지는 않습니다.

## 배포 무결성

- GitHub Actions 전체 회귀·컴파일·서명 검증·에뮬레이터 테스트가 모두 통과한 경우에만 이 시험 릴리스를 생성합니다.
- 파일명과 동일한 버전의 SHA256SUMS를 동봉하며, 커밋별 고유 시험 태그로 과거 빌드를 구별합니다.
- Google Play 또는 정식 판매는 영구 릴리스 서명키, 실물 기기 테스트, 제품별 호환표, 개인정보 고지 및 Play 심사를 따로 충족해야 합니다.
