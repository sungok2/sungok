# 실물 장치 시험 체크리스트 — M0.5

환경: Galaxy S20 Ultra Android 13 / USB OTG 허브(기기 전원이 충분하지 않으면 외부 전원) / 승인된 테스트 기기만 사용.

| 시험 | 통과 기준 | 결과 |
|---|---|---|
| 실제 Gradle 빌드 | `:app:assembleDebug` 성공 / APK 존재 / 크기·SHA-256 기록 | 미실시 |
| 설치 | `adb install -r` 성공 및 실행 시 강제 종료 없음 | 미실시 |
| USB 탐지 | 프린터·스캐너 연결/분리 시 목록 일치 | 미실시 |
| USB 권한 | 시스템 승인/거부 반영, 연결 분리 시 안전 중단 | 미실시 |
| LAN eSCL JPEG/PNG | 테스트 모의 서버에서 PDF 저장 및 페이지 확인 | PC TCP 모의 통합만 통과. 갤럭시 미실시 |
| 실물 eSCL 평판 | 페이지 수·방향·크기·선명도 확인 | 미실시 |
| 실물 ADF | 2장/12장 및 급지 실패·용지 없음 시나리오 | 미실시 |
| 실물 USB eSCL | Class 7/1/4 권한 및 JPEG/PNG 실제 스캔 | 미실시 |
| 실물 PDF 인쇄 | USB IPP 지원 여부 응답, 용지 출력·오류 메시지 | 미실시 |
| HTTPS TLS | 유효한 IP SAN 인증서에서 성공, 인증서 오류·출처 변경에서 차단 | 미실시 |
| 장시간 반복 | 연결/해제 20회, 스캔 10회 후 누수·응답 정지 없음 | 미실시 |

실제 모델명, VID/PID, 펌웨어, USB Interface, 실제 매체, 문서 종류, 오류 로그를 `docs/DEVICE_TEST_RECORD.csv`에 별도 기록하십시오. **가상 테스트를 실제 장치 검증으로 기입하지 마십시오.**
