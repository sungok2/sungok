# M0.6 참고 자료 (공식 문서)

- Android USB Host overview: https://developer.android.com/develop/connectivity/usb/host
  - 사용자 동의 및 `UsbManager`의 명시적 권한을 통해서만 USB 기기 접근.
- Android Network Security Configuration: https://developer.android.com/privacy-and-security/security-config
  - target SDK에 따른 기본 HTTP 허용 정책, HTTPS 인증서/호스트 확인.
- Android PdfDocument: https://developer.android.com/reference/android/graphics/pdf/PdfDocument
  - Android PDF 페이지 생성 및 출력 API.
- Android Storage Access Framework: https://developer.android.com/guide/topics/providers/document-provider
  - 사용자 선택 URI 및 DocumentsProvider 저장 모델.

이들 문서와 모의 테스트는 제조사별 실물 스캐너·프린터 호환성을 입증하지 않습니다.
