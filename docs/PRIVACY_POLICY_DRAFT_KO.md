## 1. 처리 기능
Galaxy Universal I/O는 기기에서 USB 장치 기술자 및 프린터/스캐너 인터페이스를 조회하고, 사용자가 선택한 인쇄·스캔 데이터를 연결된 장치로 전송하거나 기기에 저장하는 앱입니다.

- **USB 연결 진단:** VID/PID, USB 장치 경로, 인터페이스, 제조사 및 제품명, 접근 권한 상태를 앱 화면에서 확인합니다. USB 시리얼번호는 사용자가 '보고서에 시리얼번호 포함'을 선택한 경우에만 보고서에 포함할 수 있습니다.
- **인쇄:** 사용자가 선택한 문서는 Android 시스템 인쇄 서비스 또는 해당 모델에서 구현된 직접 USB 경로를 통해 전송됩니다. 시스템 인쇄 서비스를 사용하는 경우 그 서비스 제공자의 정책이 별도로 적용될 수 있습니다.
- **스캔:** 사용자가 시작한 스캔 결과를 앱 메모리·임시 캐시에서 처리하고, 사용자가 선택한 저장 위치로 PDF 또는 이미지를 기록합니다.
- **선택적 LAN 연결:** eSCL 네트워크 스캔을 선택하면 스캐너와 로컬 네트워크로 통신합니다. HTTP는 암호화되지 않으며 앱에서 사용자의 동의를 요청합니다. HTTPS는 운영체제 인증서 검증을 사용합니다.
- **선택적 프린터 프로파일 조회:** GitHub에서 모델 프로파일을 가져오는 기능을 이용하면 요청을 수신한 서버는 통상적으로 접속 IP 및 요청 정보 등을 처리할 수 있습니다.

## 2. 계정·광고·분석
2026-11-22 현재 확인된 애플리케이션 소스에는 사용자 계정, 광고 SDK, 분석 SDK가 포함되어 있지 않습니다. 향후 배포판에서 기능이 변경될 경우 재검토해야 합니다.

## 3. 진단 보고서 및 보관
진단 TXT 보고서는 사용자가 저장 명령을 실행할 때 선택한 저장 위치에 기록됩니다. USB 장치 경로와 임의로 포함한 시리얼번호는 식별에 영향을 줄 수 있으므로 외부 공유 전에 검토해야 합니다. 스캔 캐시 파일의 보관·삭제 동작은 실제 릴리스 시험에서 검증해야 하며, 자동 삭제를 보장한다고 표시하지 않습니다.

## 4. 사용자 선택
사용자는 USB 접근 권한을 거부할 수 있으며, 선택적 네트워크 스캔을 실행하지 않을 수 있습니다. 이미 저장한 파일은 해당 저장 위치 또는 Android 파일 관리 기능으로 관리합니다.

## 5. 발행 전 필수 확인
실제 판매자/개발자 명칭, 연락처, 개인정보 보호 책임자 또는 문의 채널, 시행일, 지원 국가의 법률상 필수 고지사항을 추가해야 합니다. Google Play 데이터 보안 신고는 최종 앱 바이너리, 외부 연동 서비스 및 실제 데이터 전송을 근거로 별도 검증해야 합니다. 이 초안을 최종 법률 문서나 심사 통과 증거로 사용하지 마십시오.
