# STORY ENGLISH 3.7.2 — Adult Audio Lab 독립 검토용 빌드

## 제품과 검토판 구분
- 기존 STORY ENGLISH 3.7.0 소스 통합본이 아닙니다. `com.storyenglish.audiolab`은 기존 앱과 별도로 설치되는 연구용 검토 APK입니다.
- 기존 사용자 계정, 서버, AI 대화, 기존 스토리 24편 및 원본 영상·음성은 포함하지 않습니다.
- 제공 콘텐츠 3개 장면은 성인 간 키스 전 동의, 친밀감·경계, 피임/성 건강 영어 대화를 다루는 창작 예제입니다. 의복을 입은 성인 일러스트와 기기 합성음(TTS)을 사용합니다. EXPLICIT 누드/성행위 영상은 포함하지 않으며, 원본 콘텐츠의 적법한 이용권과 연령 접근통제 확보 전 배포하지 않습니다.

## 신규 학습 기능
- 학습 문장 선택, 반복 듣기 1·2·3·5·10회, 문장 간격 0·1·2·3·5·8초.
- 오디오 재생 16kHz PCM, 마이크 녹음 16kHz PCM(마이크 권한 필요). 화면에서 3·2·1 카운트다운 후 자동 녹음 개시. 발화를 감지한 후 약 1.3초 정적이면 자동 종료, 상한 10초.
- TTS의 실제 합성 PCM과 마이크 PCM을 FFT 기반 스펙트로그램으로 표현. DTW 정렬 스펙트럼/리듬/길이의 음향 유사도 제시. 동일 인물·목소리·장비의 차이에 민감하며 발음 정확도·CEFR 인증·ASR 단어 인식과 다릅니다.
- 결과값에 따라 오리지널 효과음 음정 패턴 차등 적용(설정에서 비활성화 가능).
- 녹음 PCM은 메모리 내 분석 직후 파기하며 서버 업로드·파일 저장하지 않습니다. 앱에 기록되는 것은 시도 횟수와 최고 음향 유사도, UI 설정뿐입니다.
- Android TTS 엔진 및 영어 음성 팩 미설치/권한 거부/무음/녹음 실패 시 제한사항을 화면에 표시합니다.
- 성인 자기 확인은 19세 이상 여부의 법적 인증 수단이 아닙니다.

## 검증 범위와 출시 조건
- 검증 대상: 오프라인 Android 프로젝트의 Gradle 컴파일, Unit 테스트, Android Lint, 서명, APK 매니페스트.
- 별도 검증: 마이크 권한과 음성 재생 타이밍, TTS 엔진별 PCM 출력, 장치별 음향 지연, 접근성/화면 회전, 저사양 기기에서 DSP 실행 성능 및 콘텐츠 이용권/연령 확인.
- 영구 설치/업데이트용 빌드에서는 프로덕션 서명키를 GitHub Actions 비밀 설정에서 안정적으로 관리해야 합니다. 검토판은 CI마다 생성하는 일회용 서명키를 사용하므로 업그레이드 설치가 되지 않습니다.
- 대규모 유료 콘텐츠/EXPLICIT 매체는 합법적 사용권·출연자 동의·연령 확인·콘텐츠 등급·권리 철회 통제 확보 전 탑재하지 마세요.
