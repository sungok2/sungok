# STORY ENGLISH 3.7.1 OFFLINE UX PREVIEW
This is an independent NATIVE Android UI preview, not the original 3.7.0 app or a production release. Original source is unavailable.
- Package com.storyenglish.preview, version 3.7.1-preview.1; Android API26+
- Home, listening with system English TTS, Korean captions, comprehension quiz, writing (input not saved), review, local progress, settings
- No internet or microphone permissions; no original backend, login, AI, Media3/video, M/E access, original episodes, data migration
- Sample dialogue is newly authored non-explicit education content.
- CI uses a short-lived preview signing key, so builds cannot update each other.
Production release requires original 3.7.0 Android source, merge+regression, protected stable signing key, production API, rights/age controls, human approval and device QA.
